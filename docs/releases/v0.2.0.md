# v0.2.0 — Meet Leo

Leo joins Mafe as a second reactive pixel-art pet for Pi. Choose your companion with one command:

```text
/emote pet
```

## Added

- Leo, an orange-and-white cat with 24 reaction states and 76 transparent pixel-art frames.
- A native Mafe/Leo picker that marks the active pet, switches immediately, and remembers your choice across sessions.
- Existing reaction previews and `/emote demo` now use your selected pet. Canceling the picker leaves everything unchanged.

## Improved

- Isolated asset verification: checking generated artwork no longer overwrites project files.
- Focused tests for artwork identity, animation boundaries, pet selection, and package integrity.
- Version checks compare the manifest, lockfile, and packed version instead of requiring a fixed release number.

Mafe remains unchanged and is the default when no preference or custom mapping selects another set. Changing pets stops any preview and returns to idle. If saving the preference fails, the current pet stays active.

## Validation

- Both pets and the picker were tested interactively by the maintainer.
- Automated tests, generated-artwork verification, and package validation must pass on the release candidate.

This GitHub release does not publish the package to npm; npm publication is a separate step.
